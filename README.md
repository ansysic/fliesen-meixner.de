# Fliesen Meixner

Diese Website wird auf GitHub Pages unter der Domain aus der `CNAME`-Datei gehostet.  
`index.html` ist die Startseite; `datenschutz.html` und `impressum.html` enthalten die rechtlichen Seiten; Styles, Skripte und Bilder liegen in den Ordnern `css/`, `js/` und `img/`; die originalen Logo-Design-Dateien liegen im Unterordner `img/logo_design_files/`.
